# LIFE SIGNAL AI
## Personal Financial Intelligence System

### Project Overview
An end-to-end personal finance analytics project
that analyzes income, expenses, spending patterns,
and unusual transactions.
## Dashboard Preview

![LIFE SIGNAL AI Dashboard](dashboard_preview.png)

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- MySQL
- Streamlit
- Tableau

### Key Features
- Data cleaning and preprocessing
- Exploratory Data Analysis
- Income and expense analysis
- Monthly spending trends
- Category-wise expense analysis
- Account-wise expense analysis
- AI-based anomaly detection using Isolation Forest
- Interactive Streamlit dashboard
- Tableau visualization dashboard

### Project Results
- Total Transactions: 549
- Total Income: ₹358,061
- Total Expenses: ₹686,611
- Net Balance: -₹328,550
- Unusual Transactions: 26
- High-Spending Transactions: 3

### Project Structure
- Data/Raw
- Data/Cleaned
- Data/Processed
- Python
- Reports/figures

### Disclaimer
Anomaly detection identifies unusual spending patterns.
It does not confirm fraud.
